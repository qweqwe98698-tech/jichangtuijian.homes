你大概是在某个套餐页上看到了「原生 IP 解锁」和「DNS 解锁」，或者刚经历过一次「昨天能看今天不能看」。这一篇只讲机制：平台用什么判断你在哪、机场能改动其中的哪一段、这个判断为什么注定会翻脸。排查动作看 [Netflix 解锁排查](/fix/netflix-not-unlocking/)，机场的解锁宣称名单看[流媒体机场专题](/streaming-airport/)，IP 类型定义看[原生 IP 与机房 IP](/learn/native-ip/)。

## 「解锁」这个词实际指的是什么

它不是破解，也不涉及绕过任何付费环节，指的是：**让平台把你识别为某个目标地区的正常用户，从而提供该地区的内容库**。

之所以需要它，是因为播放权**逐个地区谈**：同一部作品 A 地有授权、B 地没有，平台必须先确认你在哪。所以解锁的对手不是加密，是**地理判定**。

## 平台判断你在哪：一条至少四段的链路

拆开看至少有四段独立信息，任何一段都可能推翻其他几段：

1. **域名解析**：设备问「视频服务器在哪」，答案本身就带地区倾向，平台用它做第一层分流。
2. **连接来源 IP**：真正来取内容的那个地址，权重最高的一段。
3. **属性评分**：这个地址登记在谁名下、像不像家庭宽带、同时有多少人在用、有没有异常历史，是动态的。
4. **账号侧信息**：注册地区、付费方式归属地、账号最近的使用地区。

第 1、2 段是「你说你在哪」，第 3 段是「你说得可不可信」，第 4 段是「你以前说过什么」。**机场只能动前两段**；第 3 段它只能努力维持，第 4 段完全不归它管。

## 两条技术路线：换来源，还是换解析

| 维度         | 换出口 IP（落地方案）        | 换域名解析（DNS 方案）             |
| ------------ | ---------------------------- | ---------------------------------- |
| 动的是哪一段 | 第 2 段，连带影响第 1 段     | 只动第 1 段，第 2 段仍是原出口     |
| 覆盖范围     | 该出口上的全部流量           | 只覆盖机场维护到的那些域名         |
| 平台适配     | 天然通用，新平台不需额外维护 | 逐平台维护，漏一个域名就漏一个平台 |
| 稳定性来源   | 取决于属性评分能维持多久     | 取决于是否持续跟进域名与解析变化   |
| 典型成本     | 高，通常伴随更高倍率或价位   | 低，可以做进便宜套餐               |
| 主要代价     | 资源有限、名额紧张           | 覆盖不完整，平台更新时先失效       |

这解释了一个常被误读的现象：**同一节点，网页能看、App 不能看**。它几乎是 DNS 方案的招牌症状——主站域名维护了，接口域名没维护。换出口方案不会「挑客户端」。

## 为什么会出现「只剩自制内容」这一档

这是最容易被当成故障的状态：能登录、能播放、界面正常，但片库明显变薄，剩下的基本都是平台自己出品的内容。

原因在于两类内容的门槛不同。**自有版权内容**平台自己说了算；**授权内容**则必须能向权利方交代「这个观众确实在授权覆盖的地区」。当属性评分不足以支撑这个交代时，平台就只提供不需要交代的那部分。

所以它本身就是诊断信息：流量走通了、账号与客户端都正常，问题精确落在**出口的属性判定**上，重装 App、切清晰度都不会有变化。

## 解锁失效的三个来源

失效不是意外，是这套机制的必然结果：

**一、共享密度上升导致的自然衰减。** 出口刚投用时人少、行为分散，评分很好；用的人多了，同一地址上的并发与行为越来越不像一个家庭，评分随之下滑。**使用本身就是衰减**——这也是极低价方案解锁必然短命的原因：它得把大量用户压在少量出口上。

**二、地址属性数据的更新。** 归属与使用类型的判定依赖第三方数据库，而这些库会持续更新。今天标为家庭宽带的一段，下月可能被重新标记，机场无法预知，只能事后更换。

**三、平台侧策略调整。** 判定的权重与阈值会调整，内容从不公布，表现出来就是**大面积同时失效**：同一时间很多人都不行时，换节点意义不大，该等机场公告。

所以评价一家机场的解锁，不看它某天能不能用，而看这三类失效后它的反应速度。可核验的观察方式见[稳定性核验指标](/guides/stability-signals/)。

## 五个常见误解

- **「解锁 = 破解」**：不是。它改的是地理判定的输入，与加密、付费墙无关，你依然需要正常订阅。
- **「原生 IP 一定能解锁」**：原生只让第 2 段更可信，第 3 段的共享密度与第 4 段的账号信息都可能推翻它。
- **「解锁一个平台等于解锁全部」**：各平台判定权重不同，DNS 方案更是逐平台维护，必须分平台验证。
- **「失效了就是机场骗人」**：自然衰减是固有属性，合理的标准是失效后多久恢复、有没有公告。
- **「有一份解锁对照表就够了」**：任何清单都是核查时点的记录，不是承诺。**时间戳超过一两周的，只能当参考。**
