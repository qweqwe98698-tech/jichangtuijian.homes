Clash 是中文用户使用最广的代理客户端体系，也是新手困惑最集中的地方——因为「Clash」这个词今天指的不是一个软件，而是一整个生态。这篇教程按「装 → 导 → 选 → 验」四步走完，每步都给你一个**检查点**：确认做对了再进下一步。

## 开始前：准备两样东西

1. **一个有效的机场订阅**：机场用户中心里那条「Clash 订阅链接」。还没有机场，先读[选择指南](/guides/how-to-choose/)再回来。
2. **一台 Windows 或 macOS 电脑**：本文以桌面端为例；Android 用户流程类似，iOS 用户请看 [Shadowrocket 教程](/apps/shadowrocket-guide/)。

## 第一步：选对客户端（新手最大坑）

原版 Clash 与 Clash for Windows 已于 2023 年停止维护，**不要再找它们的安装包**（网上流传的旧安装包还可能被植入后门）。当前的主流选择：

| 客户端                 | 平台                    | 说明                                |
| ---------------------- | ----------------------- | ----------------------------------- |
| Clash Verge Rev        | Windows / macOS / Linux | mihomo 内核，社区活跃，本文以它为例 |
| mihomo party           | Windows / macOS / Linux | 同内核的另一选择，界面风格不同      |
| Clash Meta for Android | Android                 | 移动端主流                          |

**检查点**：从项目的 GitHub Releases 页面下载安装包，而不是搜索引擎广告位。装完能打开主界面即为成功。

## 第二步：导入订阅

1. 登录机场用户中心，找到「Clash 订阅」或「一键订阅」，点击**复制链接**（不是复制邮箱注册的账号密码——订阅链接才是配置的载体，原理可参考[协议知识](/learn/protocols-explained/)）。
2. 打开 Clash Verge Rev → 左侧「订阅」（Profiles）→ 粘贴链接 → 导入。
3. 导入成功后会出现一张配置卡片，点击选中它（卡片高亮）。

**检查点**：配置卡片显示了流量信息或节点数量。若导入报错，先确认链接完整（有没有少复制字符），再看[订阅导入失败的排查](/fix/)。

## 第三步：选模式和节点

1. **代理模式选「规则」**。这是日常使用的唯一正确答案：国内网站直连不减速，国外流量自动走代理。全局模式只在排障时临时使用。
2. 进入「代理」页，对节点组做一次**延迟测试**（闪电图标）。
3. 选一个延迟数值正常（一般 <300ms）且地区合适的节点：日常选日本/新加坡/香港等近距离大区；特殊场景按需选择（AI 场景的选法见 [AI 场景标准](/best/ai/)）。

**检查点**：所选节点有具体延迟数字而非「超时」。

## 第四步：开系统代理并验证

1. 回到主页，打开「系统代理」开关。
2. 浏览器访问一个国外站点（如 Google），能打开即基本成功。
3. 再做一次完整验证：访问 IP 检测网站，确认显示的 IP 归属地与所选节点一致。

**检查点**：外网可访问 + 出口 IP 与节点一致 + 国内网站速度不受影响（说明规则分流在工作）。三条全中，恭喜你配置完成。

## 常见错误速查

- **开了代理反而全部网站打不开**：多半是端口冲突或上次异常退出残留了系统代理设置。关闭系统代理开关再重开；仍不行就重启客户端。
- **部分网站能开部分不能**：规则没覆盖到，把对应域名加入代理规则，或临时切全局模式验证。
- **昨天还能用今天全超时**：症状指向订阅或机场侧，按[节点全部超时怎么办](/fix/nodes-all-timeout/)从上往下排。
