v2rayN 的问题有个特点：报错少，界面上看不出哪里不对，于是很多人开始乱改设置。这篇按症状分路，每条路的判断依据都明确到「看到什么就说明是这一层」。

## 四种症状，四条不同的路

| 症状                   | 最先怀疑的位置                         |
| ---------------------- | -------------------------------------- |
| 全部节点超时           | 内核未运行、系统时间偏差、订阅信息过期 |
| 能测出延迟但网页打不开 | 系统代理未开启或端口不匹配             |
| 订阅更新失败           | 订阅地址、格式、拉取通道               |
| 只有个别节点连不上     | 该节点本身或协议适配                   |

## 开始之前：把三个基础状态确认掉

这三项花不到一分钟，却能解决相当一部分问题：

1. **托盘图标状态**：程序是否真在运行，而不是启动失败后退到后台。
2. **系统时间**：多数协议对时间偏差敏感，时间不准会导致握手失败，表现就是全部超时。打开自动同步校准一次。
3. **管理员身份**：涉及系统代理或虚拟网卡时，权限不足会让设置写不进去。

## 症状一：全部节点超时

按这个顺序查，命中率从高到低：

1. **更新订阅**。机场换节点地址是日常动作，你本地存的是旧信息。更新后节点数量或名称有变化，基本就是这个原因。
2. **核对系统时间**。这一项在 v2rayN 上的命中率明显高于其他客户端。
3. **确认内核进程存在**。核心类型与实际内核文件不匹配时，界面正常但没有流量。
4. **换协议试**。公司网、校园网对传输特征的处理差别很大，各协议取舍见[协议知识](/learn/protocols-explained/)。

仍然全灭就转到[节点全部超时的排查顺序](/fix/nodes-all-timeout/)，那篇会带你查账户与机场侧。

## 症状二：能测出延迟，网页却打不开

**这是 v2rayN 最典型的「假连上」。** 延迟测试由客户端自己发起，不经过系统代理；浏览器的流量却必须走系统代理才能进入客户端。两者互不相干，所以延迟正常和网页打不开可以同时成立。

- 把系统代理开关切到**自动配置系统代理**模式，重新访问。恢复即命中。
- 打开系统代理设置页，确认地址与端口和 v2rayN 的本地监听端口一致。
- 浏览器里的代理管理类插件会覆盖系统设置，先禁用再测。
- 规则模式下部分域名被放行为直连，也会造成「有的能开有的不能」，先切全局验证。

## 症状三：订阅更新失败

先定位方向：把订阅链接粘进浏览器直接打开。返回一长串编码字符说明地址有效，问题在客户端侧；打不开或空白说明地址或账户侧有问题。

v2rayN 需要它能解析的订阅格式，**不要把 Clash 系专用的那条链接导进来**。完整的分级排查见[订阅更新失败的排查顺序](/fix/subscription-update-fail/)。

## 症状四：只有个别节点连不上

最不需要紧张的一种。个别节点故障、维护、被封是常态，换一个即可。只有同一分组内**大批节点同时**失效才值得往上查。

## 内核与版本：容易被忽略的一层

客户端本体和内核是两个东西，很多疑难问题出在错位：升级了客户端但内核没同步、配置指定的核心类型与实际内核文件不一致、内核被安全软件误删。

**判断依据**：看程序自带的日志窗口。没有任何连接记录说明内核根本没跑起来；有记录但握手失败，才是协议或参数问题。

## Windows 侧的三个常见拦路点

1. **防火墙与安全软件**：把程序目录整体加入信任，尤其在内核文件被反复清除时。
2. **端口占用**：提示占用就在参数设置里换一个本地监听端口，改完重启客户端，并同步修改系统里填写的端口。
3. **同时运行多个客户端**：两个客户端抢同一组端口和系统代理设置，结果是谁都不正常。一次只留一个。

## 全部试完仍不通：交叉验证的正确做法

把**同一条订阅导入另一个客户端**，在同一台电脑、同一条网络上测：

- 另一个客户端正常 → 问题在 v2rayN 的配置或环境，回到内核与端口两节。
- 另一个客户端也不正常 → 与 v2rayN 无关，问题在订阅、账户或机场侧。

Clash 系客户端的导入方式见 [Clash 教程](/apps/clash-guide/)，作为对照工具很合适。

## 使用 v2rayN 的几个稳妥习惯

- **只从官方发布渠道下载客户端与内核**。整合包、破解版、群文件里流传的安装包都不要用——它拿到的正是你的全部流量。
- **订阅链接等同账户凭证**：不外发、不截图、不贴进在线转换工具；怀疑泄露就去用户中心重置。
- 开启启动时自动更新订阅，保留一份可用配置的备份，方便改坏设置后快速回退。
